# Mushroom Scout 圖示盤點與提案範圍

更新：功能圖示已於 brand/ui/v0.6/ 補齊交付。原 Android enum 為 52 個用途，另補 4 個 iOS 語意用途，總共 56 個用途、92 個獨立 glyph。以下三組風格段落保留作歷史提案，現行內容／品牌風格以非擬人化 v0.5 為準，功能圖示維持 Phosphor。

依現有 Android 主程式、SwiftUI 畫面與種類資料盤點；設計提案不修改 App。

## 功能圖示：52 個語意用途

| 分組 | 圖示用途 |
| --- | --- |
| 地圖與頂列 | 搜尋、圖層、篩選、設定、準星、目前位置、顯示全部、放大、縮小 |
| 主要入口 | 自動、任務、紀錄、掃描 |
| 自動功能 | 餵果、派遣、抽獎；派遣為現有 enum 保留項，重新設計派遣目前未啟用，不作主要入口 |
| 底部與地點 | 傳送、路線、拖曳排序、清單、足跡、時區、收藏、最近 |
| 操作 | 新增、移除、復原、旋轉、開始、暫停、停止、複製、外部開啟、分享、刪除、確認、關閉、更多、下一步、上一步 |
| 懸浮工具 | 功能選單、票券、光速移動、退格、回到 App |
| 導覽 | 返回、上一頁、下一頁、展開、收合 |
| 狀態 | 資訊、警告 |

來源：`android/app/src/main/java/io/github/yaossr02/mushroomscout/ui/AppIcon.kt`。52 是用途數；新增／放大、移除／縮小共用圖形，因此不是 52 個獨立圖形。現有規則採 Phosphor Bold／Fill，動作圖示維持單一形態。iOS 的設定、成功、警告、空心狀態可沿用相同語意。

## 內容圖示

| 分組 | 必備樣式 |
| --- | --- |
| 顏色蘑菇 | 紅、黃、藍、紫、白、灰、粉紅、冰藍，共 8 種 |
| 元素蘑菇 | 火、水、電、毒、水晶，共 5 種；形狀必須可區分，不能只換色 |
| 特殊蘑菇 | 活動、種類不明，共 2 種 |
| 尺寸變體 | 小、一般、大、巨大；共用基本圖，搭配尺寸與大／巨徽章，不需每種重畫 |
| 大花狀態 | 葉芽、花苞；完整開花可作未來擴充，不列為已確認現有圖示 |
| 地圖輔助 | 足跡、群聚數字、選取與進行中狀態；優先使用功能圖示與外加標記 |

來源：`core-kotlin/.../core/Kinds.kt`、`ui/MushroomIcons.kt`、`ui/MapScreen.kt`。分類器目前列出 36 個已知種類標籤；顯示圖示採基本樣式與尺寸組合。分類器用的模板與 HOG 素材不屬於 UI 圖示，重新設計時不應替換。

## 品牌與輸出規格

- App 主圖示：Android adaptive foreground/background、單色 themed icon；iOS AppIcon 可共用品牌構圖。
- Android 通知：單色蘑菇輪廓，不能直接用彩色插畫縮小。
- 功能圖示以 16／18／20 dp 清晰度為優先，觸控區至少 48 dp；未選／已選須可辨識。
- 地圖內容圖示要有固定腳底定位點，輪廓能在地圖上辨識。
- 概念圖板只作風格選擇，尚非逐顆可匯入的 SVG／PNG 正式資產。

## 三組方向

| 方案 | 視覺 | 適合原因 |
| --- | --- | --- |
| A 森林繪本 | 平面色塊、柔和深綠描邊、鼠尾草綠與奶油白、珊瑚紅點綴 | 最接近現有自然主題，小尺寸辨識度最好；優先推薦 |
| B 奶油軟糖 | 圓潤軟糖形、極輕柔立體陰影、奶油與杏桃／薄荷／薰衣草色 | 可愛感與品牌辨識強；小尺寸功能圖示需採同系列平面簡化版 |
| C 北歐花園 | 幾何剪紙、留白、低彩度植栽配色、幾乎無描邊 | 最簡約成熟；需以清楚輪廓與狀態差異保持可讀性 |

三組以相同代表題材渲染：App 品牌、15 種基本蘑菇、葉芽／花苞、尺寸徽章、主要功能與單色縮小預覽。全套 52 個用途待選定方向後再逐一製作。
