# Cream Gumdrop 品牌規範 v0.2

狀態：B 方向與紅蘑菇、火蘑菇、水晶蘑菇、葉芽 v0.1 已核准（見 approvals/2026-10-31-foundation.md）。綠色花苞 v0.2 待確認；數值 token 與正式匯出規格仍是草案。

## 核心外觀

現代簡約、圓潤可愛、霧面奶油軟糖材質。淺 2.5D 體積，左上柔光，柔和自身遮蔭。大色塊與清楚外輪廓優先；避免寫實紋理、塑膠亮面、金屬、厚描邊、閃粉與背景場景。後續素材應直接參照已核准原圖的材質與表情，避免逐代漂移。

## 角色基準

- 蘑菇：短而飽滿的奶油白菇柄，兩顆深可可直橢圓眼、小微笑、淡杏桃腮紅；不加手腳。所有元素型沿用同一個角色族群。
- 紅菇：珊瑚紅圓頂，5 個大奶油白斑點。brand/approved/v0.1/red-mushroom.png 為已核准的主角色參考。
- 火菇：外珊瑚橘、內奶油黃的圓鈍火焰帽；無寫實火焰或火星。
- 水晶菇：冰藍／淡紫，中央高、兩側低的三主晶簇輪廓，少量大片切面；不能只替紅帽換色。
- 葉芽與花苞沒有臉。葉芽兩片主葉；花苞閉合淺綠色花瓣（使用者明確指定綠色，不得沿用舊粉色圖板），兩片側葉與綠萼。
- 蘑菇腳底以少量鼠尾草葉承托；植物以簡單暖棕土石承托。已核准角色的葉片與眼睛高光以原圖為準；花苞細節隨 v0.2 另行檢閱。

## 畫布與定位

未來目標輸出為 RGBA PNG、正方形、透明背景。生成時可要求 1024×1024，但必須記錄實際尺寸：本批原稿為 **1254×1254**，不能偽稱已符合 1024 輸出。

建議主體留白約 15%，腳底定位點在畫布寬度 50%、高度 85% 附近；生成不保證精準。目錄記錄 alpha >=128 的實際主體 bbox 與其底部中心作為暫定 anchor。正式匯出前需光學對齊並由使用者確認。

目前 PNG 有透明通道，但也有非常低 alpha 的外圍像素；不能只憑透明通道存在就稱邊緣乾淨或可直接上線。需在白、深色與棋盤背景檢閱；正式資產整理另行進行，不覆寫候選原稿。

## 小尺寸與地圖

以原始 PNG 在 32／48／64 CSS px 畫布檢閱；這些是畫布尺寸，含原稿留白，並非角色本體高度。不要把生成圖板的文字尺寸當成實測。

檢查紅／火／水晶輪廓是否可分辨、花苞與葉芽是否混淆；小尺寸允許五官消失，但種類輪廓不能消失。HTML 地圖是定位示意，不代表已在 Android／iOS 實測。

## 功能圖示與品牌邊界

B 的可愛角色用於蘑菇、植物與品牌內容。功能圖示先保留現有 Phosphor Bold／Fill 與 16／18／20 dp 規則；不要自動將所有介面圖示立體化。App launcher／通知單色圖待後續任務製作。分類器模板與 HOG 資料不是 UI 素材，不能替換。

## 核准與版本

使用者明確核准某個 ID 與版本後，才將其列為 approved 並保存核准記錄與 hash。新稿、變體及修圖不自動繼承核准。所有 approved 素材保留不可覆寫的版本，新稿放 candidate。沒有核准參考時，延續 B 圖板並說明限制。
