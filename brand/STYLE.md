# Cream Gumdrop Botanical 品牌規範 v0.5

## 最新使用者要求

「蘑菇都不要擬人化，整個設計重新調整。」本要求取代 v0.1–v0.4 的角色五官與身體造型規範。新版所有蘑菇、尺寸／狀態預覽、App 主圖示與平台單色圖都必須是非擬人化自然物件。

舊核准紀錄只代表當時的審核歷史；catalog 中 active_reference:false 的版本不能再當生成參考，也不能匯入新版 App。新版 v0.5 全是待核准候選，不繼承舊核准。

## 外觀與禁止事項

- 保留 B 的現代簡約、圓潤、霧面奶油軟糖質感與柔和 2.5D 體積。可愛來自自然比例、圓角與配色，而非人物表情。
- 蘑菇使用自然短柱狀／微收腰奶油白菇柄，帽下可有簡化菌褶。菇柄不是頭、肚子或人物身體。
- 絕對不加眼睛、高光眼、眉毛、嘴巴、微笑、腮紅、臉、表情、手腳、四肢、服裝或人物配件。菇柄完全素色，不留像五官的對稱斑點或凹痕。
- 低矮鼠尾草葉叢是自然基底，不能像成對手臂或腳掌。
- 活動蘑菇採星形斑紋／帽緣，不使用派對帽、服裝。未知種類問號僅是帽面功能標記，不是表情。
- 左上柔光、簡單陰影與清楚輪廓；避免寫實紋理、塑膠亮面、厚描邊、閃粉、場景與外部大投影。

## 全系列

八色：紅、黃、藍、紫、白、灰、粉紅、冰藍；白帽配暖米色斑點，藍與冰藍須可分。元素：火、水、電、毒、水晶，靠帽型與元素區分。特殊：活動、未知。葉芽與綠色花苞沿用已核准、沒有臉的原圖，花苞維持綠色。

## 參考優先序

使用已核准、符合最新規範且 active_reference 不為 false 的素材；目前植物符合。蘑菇沒有新版核准稿時，以 brand/candidates/v0.5/red-mushroom.png 作候選方向參考，清楚記錄尚未核准。不得退回帶臉 B 圖板或歷史角色。

## 尺寸、狀態與輸出

固定腳底 anchor，保留小／一般／大／巨大倍率 0.85／1／1.15／1.3。徽章、外圈與狀態文字獨立於蘑菇圖層，不在菇柄加表情。功能圖示維持 Phosphor。

PNG 必須記錄實際尺寸、RGB／RGBA、alpha、hash 與 bbox。要求 1024px 不等於實際輸出 1024px；正式輸出仍要整理低 alpha 邊緣與光學大小，不把 PNG 偽裝成 SVG。以原圖在淺深底、32／48／64 CSS px 檢閱。平台遮罩與安全圈不是 App 或實機測試。分類器模板與 HOG 不是 UI 素材，不能替換。
