## 視覺語彙

1. **墨綠實心主體**：Ink `#2E3A2F`，輪廓厚實圓潤；以大形狀辨識用途。
2. **連續奶油貼紙邊**：Cream `#FFF1DB` 沿真實圖形輪廓繞行，外面再有 Ink keyline，避免和暖白圓底融在一起。不是加通用的圓形／方形背景牌。
3. **單一珊瑚紅重點**：Coral `#F36C63`，集中於箭頭、按鈕或一段主筆畫；避免零碎小點與到處點色。
4. 同套的線重、圓角、內外留白、主體光學大小一致；少量清楚的留白可交代結構，不堆細節。
5. 限三種平面色：Ink／Cream／Coral。沒有漸層、陰影、高光、金屬反光、玻璃、霓虹或紋理。
6. 不加文字、emoji、手、五官、表情或人物肢體；蘑菇保持自然形狀。

這套是使用者選定的個別圖形，不要為了統一而把每個圖示都畫成金盆或加葉子。只借用金盆的厚實實心、圓角與貼紙輪廓語彙。

## 版型與檢閱

- 透明 RGBA PNG，1254×1254，約 8% 安全邊；不是 SVG／VectorDrawable。
- 懸浮按鈕：40dp 暖白 `#FFFCF6` 圓，圖示預設20dp，另驗24dp，下方深色膠囊短標籤。
- 必須在高飽和綠草地、花與蘑菇的雜訊背景上看，不能只看白底。
- 要交原比例、放大比較、32／48／64px、20／24dp，以及必要的新舊稿對照。80／96px 對應 xxxhdpi 的20／24dp。
- 目前檢閱使用模擬遊戲場景，尚未取得實機附件，沒有宣稱完成 Android overlay 實機驗證。

## 製作與保存方法

以 image_gen 產生獨立原圖，每個語意各有檔案，不能從比較圖裁切正式素材。保存實際完整提示詞、附圖來源、原始模型輸出、日期、尺寸、alpha、bbox 與 SHA-256。使用新版本目錄，不覆蓋核准原圖。

使用者已允許 Python 做機械限色、透明邊緣和尺寸整理；保留原始生成稿。避免大幅輪廓加粗：先前這種處理曾把金盆盆口、幼苗與箭頭間隙擠壞。涉及形狀或方向的修正應回到圖片工具，逐張視覺檢查。

特別檢查 SkipBack／SkipForward 的內外三角形方向都正確；Stop 不得因色塊中央多出一個洞而像錄影符號。

## 核准與工程驗證分開

使用者已核准這16張的視覺選用，但不等於數值幾何檢查全部通過。保留原定目標：20dp最細線寬≥1.75dp、點綴最小邊≥3dp；金盆下箭頭軸寬≥3dp，24dp也要驗證。現有距離場p10只是篩檢估值，不是精確最細筆畫認證，仍有警示，見交付 manifest 所列警示。

Ink 對暖白對比約11.636:1；珊瑚紅對暖白約2.874:1，使用者明確選擇保留品牌紅、以墨綠邊界維持辨識；不要宣稱純紅已達3:1。Cream用於輪廓與留白，外側須有Ink分隔。

Claude 應在實際遊戲背景、真實20／24dp與互動狀態驗證。需要改核准形狀或用新加粗稿時，另存新版本並回報，不要靜默重畫核准PNG。
